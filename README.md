# 구글 드라이브 폴더 동기화 (옵시디언 아이폰용 플러그인)

아이폰 옵시디언 볼트를 구글 드라이브 폴더(공유 폴더 포함)와 양방향으로 맞춥니다.
PC는 지금처럼 구글 드라이브 데스크톱 앱(H: 드라이브)으로 같은 폴더를 쓰면 되고, 이 플러그인은 아이폰에만 깔면 됩니다.

## 동작 방식
- 옵시디언을 켤 때, 그리고 5분마다(설정 가능) 자동으로 동기화합니다. 왼쪽 리본의 ⟳ 아이콘으로 바로 동기화할 수도 있어요.
- 한쪽에서만 고친 파일은 그쪽 내용으로 맞춥니다.
- **양쪽에서 모두 고친 파일**은 원래 이름에 드라이브 내용을 두고, 아이폰 내용은 `이름 (아이폰 충돌 날짜).md`라는 사본으로 남깁니다. 어느 쪽 내용도 지우지 않아요.
- 지운 파일은 휴지통으로 보냅니다(드라이브 휴지통 / 볼트의 `.trash`). 한 번에 많이 지워지게 되면 동기화를 멈춰요.
- `.obsidian` 같은 점(.)으로 시작하는 폴더, 구글 문서·스프레드시트는 동기화하지 않습니다.

## 1. 구글 로그인 키 만들기 (PC에서, 처음 한 번)
1. https://console.cloud.google.com 에 접속해서 새 프로젝트를 만들어요(이름 예: `obsidian-sync`).
2. **API 및 서비스 → 라이브러리**에서 `Google Drive API`를 찾아 **사용**을 눌러요.
3. **OAuth 동의 화면**(Google 인증 플랫폼)을 설정해요.
   - 사용자 유형: **외부**
   - 앱 이름과 이메일만 넣고 나머지는 비워 둬도 돼요.
   - 범위는 추가하지 않아도 돼요.
   - **대상(테스트 사용자)에 내 구글 계정을 추가**해요.
   - 마지막으로 **앱 게시(프로덕션으로 푸시)**를 눌러요. 테스트 상태로 두면 7일마다 로그인이 풀려요. 검증 신청은 하지 않아도 돼요.
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**를 눌러요.
   - 애플리케이션 유형은 **데스크톱 앱**으로 골라요.
   - 만들어지면 **클라이언트 ID**와 **클라이언트 보안 비밀번호**를 메모해 둬요.
5. 볼트로 쓸 드라이브 폴더(`안전담당자 공유메모`)를 웹 구글 드라이브에서 열고, 주소창 주소(`https://drive.google.com/drive/folders/...`)를 복사해 둬요.

## 2. 아이폰에 플러그인 넣기
1. 옵시디언에서 **이 iPhone에** 저장하는 새 볼트를 만들어요(iCloud는 끄기).
2. 설정 → 커뮤니티 플러그인 → 제한 모드를 꺼요.
3. **찾아보기**에서 `BRAT`을 검색해 설치하고 켜요.
4. BRAT 설정 → **Add beta plugin**에 `ZerglingL/obsidian-gdrive-sync`를 넣고 **Add plugin**을 눌러요.
5. 커뮤니티 플러그인 목록에서 **구글 드라이브 폴더 동기화**를 켜요.

## 3. 플러그인 설정 (아이폰에서)
1. 클라이언트 ID, 보안 비밀번호, 드라이브 폴더 주소를 넣어요.
2. **로그인**을 눌러 구글 계정으로 로그인해요.
   - "확인되지 않은 앱" 경고가 나오면 **고급 → (앱 이름)(으)로 이동**을 눌러요. 내가 만든 앱이라 괜찮아요.
3. 로그인이 끝나면 "서버에 연결할 수 없음" 페이지가 나와요. 이건 정상이에요.
   - 그 페이지의 **주소창 주소 전체**(`http://localhost/?code=...`)를 복사해요.
4. 설정으로 돌아와 **2. 복사한 주소 붙여넣기** 칸에 넣고 **확인**을 눌러요.
5. **동기화**를 누르면 드라이브의 노트가 내려와요.

## 개발자용

- 동기화 판단 로직 검사: `node test.js`
