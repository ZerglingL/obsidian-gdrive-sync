# 구글 드라이브 폴더 동기화 (옵시디언 아이폰용 플러그인)

아이폰 옵시디언 볼트를 구글 드라이브 폴더(공유 폴더 포함)와 양방향으로 맞춥니다.
PC는 지금처럼 구글 드라이브 데스크톱 앱으로 같은 폴더를 쓰면 되고, 이 플러그인은 아이폰에만 깔면 됩니다.
구글 드라이브와는 내 계정에 배포한 Apps Script 중계(`apps-script/Code.gs`)를 거쳐서만 주고받습니다. Google Cloud 설정이 필요 없어요.

## 동작 방식
- 옵시디언을 켤 때, 그리고 5분마다(설정 가능) 자동으로 동기화합니다. 왼쪽 리본의 ⟳ 아이콘으로 바로 동기화할 수도 있어요.
- 한쪽에서만 고친 파일은 그쪽 내용으로 맞춥니다.
- **양쪽에서 모두 고친 파일**은 원래 이름에 드라이브 내용을 두고, 아이폰 내용은 `이름 (아이폰 충돌 날짜).md`라는 사본으로 남깁니다. 어느 쪽 내용도 지우지 않아요.
- 지운 파일은 휴지통으로 보냅니다(드라이브 휴지통 / 볼트의 `.trash`). 한 번에 많이 지워지게 되면 동기화를 멈춰요.
- `.obsidian` 같은 점(.)으로 시작하는 폴더, 구글 문서·스프레드시트는 동기화하지 않습니다.

## 1. 중계 스크립트 배포 (PC에서, 처음 한 번)
1. 드라이브 폴더가 있는 구글 계정으로 https://script.google.com 에서 새 프로젝트를 만들어요.
2. `apps-script/Code.gs` 내용을 붙여 넣고 위쪽 값을 고쳐요.
   - `KEY`: 길고 무작위인 비밀 문자열
   - `PARENT_ID`, `ROOT_NAME`: 볼트 폴더의 상위 폴더 ID와 볼트 폴더 이름
3. 함수 `test`를 실행해 권한을 승인해요. 실행 로그에 파일 개수가 나오면 성공이에요.
4. **배포 → 새 배포 → 웹 앱**을 골라요.
   - 실행: **나**
   - 액세스: **모든 사용자**
5. 배포하면 나오는 웹 앱 URL 뒤에 `#KEY값`을 붙여요. 이것이 **연결 코드**예요.
   - 예: `https://script.google.com/macros/s/.../exec#비밀문자열`

코드를 고친 뒤에는 **배포 관리 → ✏️ → 새 버전**으로 다시 배포해요. URL은 바뀌지 않아요.

## 2. 아이폰에 플러그인 넣기
1. 옵시디언에서 **이 iPhone에** 저장하는 새 볼트를 만들어요(iCloud는 끄기).
2. 설정 → 커뮤니티 플러그인 → 제한 모드를 꺼요.
3. **찾아보기**에서 `BRAT`을 검색해 설치하고 켜요.
4. BRAT 설정 → **Add beta plugin**에 `ZerglingL/obsidian-gdrive-sync`를 넣고 **Add plugin**을 눌러요.
5. 커뮤니티 플러그인 목록에서 **구글 드라이브 폴더 동기화**를 켜요.

## 3. 플러그인 설정 (아이폰에서)
1. 플러그인 설정의 **연결 코드** 칸에 연결 코드를 통째로 붙여 넣어요.
2. **동기화**를 누르면 드라이브의 노트가 내려와요.

## 개발자용
- 빌드가 필요 없는 일반 JS 플러그인이에요.
- 새 버전은 `manifest.json`의 version을 올리고, `gh release create <버전> main.js manifest.json`으로 올려요.
- 동기화 판단 로직 검사: `node test.js`
